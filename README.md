# ruhzi.github.io

Jekyll source for https://ruhzi.github.io. Built by GitHub Pages; push to `main` to deploy.

- Posts: `_posts/YYYY-MM-DD-slug.md` — front-matter keys: `title, subtitle, description, series, tags, tldr, toc, cite`
- Images: `assets/img/`
- Theme: `_layouts/`, `_includes/`, `assets/css/main.css` (no external theme)

Local preview: `bundle install && bundle exec jekyll serve --livereload`
